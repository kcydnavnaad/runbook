## 🚀 Getting Started

Most scripts are plug-and-play. Clone the repo and navigate to the script you want:

```bash
git clone https://github.com/kcydnavnaad/scripts.git
cd scripts/python/example-script
python3 script.py
```

For Bash scripts:

```bash
chmod +x script.sh
./script.sh
```

Each script folder has its own `README.md` with specific instructions.
